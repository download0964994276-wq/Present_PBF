02 · Reading the Chart

What each part tells you

2017 → 2023
The Uptrend — Riel weakening
The blue line rises from 3,970 → 4,111. A rising rate means 1 USD buys more KHR — the riel is losing value. This reflects post-COVID dollar strength and rising US interest rates attracting global capital away from emerging markets.
Rate ↑ = Riel weakens = Dollar stronger
2023 → 2026
The Downturn — Riel recovering
The rate falls from 4,111 → 4,010. A falling rate means 1 USD buys fewer KHR — the riel is gaining ground. This aligns with slowing US inflation and the Fed signalling rate cuts, reducing dollar dominance globally.
Rate ↓ = Riel strengthens = Dollar softer
2027 → 2028
The Forecast — Continued mild recovery
Prophet extrapolates the post-2023 downward trend. It predicts ~3,990 in 2027 and ~3,975 in 2028 — suggesting the riel continues a slow, modest strengthening path if current macro conditions persist.
yhat 2027 ≈ 3,990  ·  yhat 2028 ≈ 3,975
The Cone
Why the CI band fans out
The confidence interval band starts narrow at the anchor and widens as years increase. This is mathematically correct — uncertainty compounds with time. A forecast 1 year out is more reliable than 2 years out. This is the most important thing to communicate about any forecast.
Wider cone = less certainty = longer horizon
Overall story in one sentence
The 10-year narrative
The KHR/USD rate rose through the COVID era and US rate-hike cycle (2020–2023), peaked at 4,111 in 2023, then began declining as dollar strength faded. The Prophet model detects this trend reversal and forecasts a continuation of the mild riel recovery into 2027–2028, though the widening CI cone reminds us that FX markets remain inherently unpredictable beyond 12 months.
03 · The Python Code

index.py — full script

index.py 
from prophet import Prophet
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    'ds': pd.date_range('2017-01-01', periods=10, freq='YE'),
    'y':  [3970, 3921, 4020, 4050, 4098,
           4089, 4111, 4073, 4013, 4010]
})

model = Prophet(yearly_seasonality=True)
model.fit(df)

future = model.make_future_dataframe(periods=2, freq='YE')
forecast = model.predict(future)
model.plot(forecast)
plt.show()        # ← required in VS Code to display window
04 · Line-by-Line

What each line does

from prophet import Prophet
Load the forecasting library. Meta's Prophet handles trends, seasonality, and missing data automatically.
import pandas as pd
Load the data library. pandas gives us the DataFrame table structure Prophet requires.
import matplotlib.pyplot as plt
Load the chart library. Needed to call plt.show() and actually display the plot window in VS Code.
pd.DataFrame({'ds':..., 'y':...})
Build the data table. 10 rows: 'ds' = year-end dates 2017–2026, 'y' = KHR/USD annual averages. Prophet demands exactly these two column names.
Prophet(yearly_seasonality=True)
Create the model. Tells Prophet to detect 12-month cycles — e.g. Khmer New Year April dip, year-end holiday demand.
model.fit(df)
Train the model. Prophet decomposes history into: trend + seasonality + residual noise. This is where all the learning happens.
make_future_dataframe(periods=2)
Extend the time axis. Adds 2 blank rows for 2027 and 2028 — the future slots the model will fill in.
model.predict(future)
Generate the forecast. Returns yhat (predicted rate), yhat_lower and yhat_upper (the CI band edges) for every row.
model.plot(forecast)
Draw the chart. Auto-generates the actual dots, fitted line, dashed forecast, and shaded CI cone.
plt.show()
Display the window. Without this line, VS Code runs the script silently — the chart is drawn in memory but never shown on screen.
